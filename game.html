§ Base64 编码

定义： Base64是一种将二进制数据转换为可打印ASCII字符的编码方式。它将每3个字节（24位）拆分为4个6位组，每个6位组映射到字符集 A-Z a-z 0-9 + /。当数据长度不是3的倍数时，用填充字符 = 补齐至4的倍数。该编码广泛用于电子邮件（MIME）、HTTP基础认证及数据URI中，也常作为信息混淆的简单手段出现在谜题中。

特征

  • 字符集限制： 仅包含大小写字母、数字、+、/ 以及末尾的 =。
  • 填充标记： 末尾可能出现 = 或 ==，使字符串长度恒为4的倍数。
  • 体积膨胀： 编码后数据量约增加33%。
  • 视觉规整： 无乱码，全为可读字符，结尾等号常为识别线索。
  • 无密钥： 并非加密算法，仅编码，故任何人均可解码。

解密方案

Base64的解密即解码过程：将每4个字符还原为3个字节，忽略填充后得到原始数据。几乎所有编程语言都内置解码函数。以下为Python与JavaScript示例，可对任意Base64字符串进行解码。

# Python 解码
import base64

cipher_text = "base64_string_here" # 替换为实际密文
plain_text = base64.b64decode(cipher_text).decode('utf-8')
print(plain_text)
// JavaScript 解码
const cipher = "base64_string_here"; // 替换为实际密文
const plain = atob(cipher);
console.log(plain);

在解谜场景中，若发现符合上述特征的字符串，直接通过工具或代码即可还原。注意，标准Base64字符集中包含+和/，而URL安全变体则使用-和_。末尾等号数量暗示原始数据长度模3的余数：一个等号表示最后16位数据（2字节），两个等号表示最后8位数据（1字节）。

注： Base64本身不提供安全性，仅用于编码传输。但在谜题中，它可作为第一层障碍，阻止不经意的窥探。
